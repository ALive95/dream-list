“Save to GitHub” commits cards.json to your repository; GitHub Pages then takes about a minute to update the Dream List. Without a token, download the file and upload it to the repo by hand.

GITHUB SETTINGS

Create a fine-grained token at GitHub → Settings → Developer settings → Personal access tokens, limited to this one repository, with Contents: Read and write. It is saved in this browser's local storage, never in the repo.
